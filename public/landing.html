How it works

Claude reads. Code checks. People decide.

01 · Claude

Reads

Turns a receipt or bill into fields with a confidence for each. It never makes the call.

02 · Deterministic code

Checks

Grant rules, duplicates, the bank feed, vendor identity and public records. Same input, same answer.

03 · Two people

Decide

One certifies, a different person releases. Every step lands in a hash-chained log.
